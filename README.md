## Hi, I'm Taha

I'm a Computer Engineering student at Bursa Uludağ University focused on AI/ML, computer vision, and autonomous robotics. I build real-time perception and navigation systems using PyTorch, OpenCV, ROS2, SLAM, and edge AI. My work includes stereo vision, object detection, visual-inertial localization, anomaly detection, and weakly supervised segmentation.
